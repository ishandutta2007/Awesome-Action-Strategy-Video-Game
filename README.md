# Awesome-Action-Strategy-Video-Game

**Curated List of Commercial Games & Open-Source Projects**
*Focused on Real-Time Tactics, Base Building, Unit Command & Strategic Combat*
**Last updated: October 2026**

This repository tracks notable **commercial action-strategy games** and **open-source projects** that blend real-time action with strategic depth—unit command, base building, resource management, and tactical combat.

**Examples** include Minecraft Legends, Mount & Blade II: Bannerlord, Overlord II, Pikmin 4, Brutal Legend, Tooth and Tail, Kingdom Two Crowns, AirMech Strike, Halo Wars 2, and SpellForce 3 (the category leaders).

This section documents these production-grade solutions.

## Commercial Games

- **[Minecraft Legends](https://www.minecraft.net/en-us/about-legends)**  
  **Action-strategy spin-off with real-time unit command.** Lead armies against piglin invasions, build defenses, and command units in a blocky world. **Support ended January 2024**—no further updates .

- **[Mount & Blade II: Bannerlord](https://www.taleworlds.com/)**  
  **Medieval action-strategy blending real-time combat with tactical command.** Command armies on the battlefield while fighting alongside them. Sieges, kingdom management, and sandbox campaigns .

- **[Overlord II](https://www.codemasters.com/)**  
  **Action-adventure with minion command mechanics.** Control hordes of gremlin-like minions to conquer fantasy realms. Dark humor and strategic minion management.

- **[Pikmin 4](https://www.nintendo.com/)**  
  **Nintendo's real-time strategy adventure with Pikmin command.** Guide small plant creatures to collect treasures, solve puzzles, and battle enemies. Multi-tasking and time management.

- **[Brutal Legend](https://www.doublefine.com/)**  
  **Action-adventure with real-time strategy battles.** Jack Black voices Eddie Riggs in a heavy metal fantasy world. Stage battles combine action combat with unit command.

- **[Tooth and Tail](https://www.toothandtailgame.com/)**  
  **Real-time strategy with fast-paced, distilled mechanics.** Command animal factions in procedurally generated maps. Simplified controls and short matches.

- **[Kingdom Two Crowns](https://www.kingdomthegame.com/)**  
  **Micro-strategy with side-scrolling exploration.** Build and defend your kingdom, recruit subjects, and expand territory. Atmospheric and minimalist.

- **[AirMech Strike](https://www.carbongames.com/)**  
  **Action-strategy with transforming mechs.** Command units while piloting a transforming mech in fast-paced combat.

- **[Halo Wars 2](https://www.halowaypoint.com/)**  
  **Real-time strategy set in the Halo universe.** Command UNSC and Banished forces with console-optimized controls.

- **[SpellForce 3](https://www.spellforce.com/)**  
  **RPG-RTS hybrid with base building and hero units.** Build bases, command armies, and level up heroes in a fantasy world.

## Open-Source Projects

### Full RTS Platforms

- **[0 A.D.](https://github.com/0ad/0ad)**  
  **The flagship open-source real-time strategy game.** **GPL-2.0 licensed**, **2,800+ GitHub stars** . **Key features**: **Historical factions** (Romans, Greeks, Persians, etc.); base building and resource management; large-scale battles; multiplayer; **free and community-driven** . **Best for**: RTS fans wanting a free, historically-themed alternative to Age of Empires.

- **[OpenRA](https://github.com/OpenRA/OpenRA)**  
  **Open-source recreation of classic Command & Conquer games.** **GPL-3.0 licensed**, **2,700+ GitHub stars** . **Key features**: Runs **Red Alert, Tiberian Dawn, and Dune 2000** with modern improvements; **online multiplayer**; map editor; mod support; cross-platform . **Best for**: Classic C&C fans wanting a modern, supported engine.

- **[Beyond All Reason (BAR)](https://github.com/beyond-all-reason/Beyond-All-Reason)**  
  **Large-scale open-source RTS with modern graphics.** **GPL-2.0 licensed**, **17,000+ GitHub stars** . **Key features**: **Two factions** with unique units; **massive battles** (hundreds of units); **physics-based projectiles**; **AI opponents**; **lobby system**; **spectator mode** . **Best for**: Players wanting Total Annihilation-style large-scale combat.

- **[Warzone 2100](https://github.com/Warzone2100/warzone2100)**  
  **Open-source 3D RTS with unit customization.** **GPL-2.0 licensed**, **4,000+ GitHub stars** . **Key features**: **Campaign and skirmish modes**; **unit designer** (customize chassis, weapons, propulsion); **3D terrain**; **research tree**; multiplayer . **Best for**: Players wanting a story-driven RTS with deep customization.

- **[Widelands](https://github.com/widelands/widelands)**  
  **Open-source Settlers-style economic strategy.** **GPL-2.0 licensed**, **3,700+ GitHub stars** . **Key features**: **Four tribes** with unique economies; **resource gathering and production chains**; **military campaigns**; **multiplayer**; map editor . **Best for**: Fans of Settlers and economic RTS.

### Tower Defense & Hybrid

- **[Mindustry](https://github.com/Anuken/Mindustry)**  
  **Open-source tower defense and factory-building hybrid.** **GPL-3.0 licensed**, **27,000+ GitHub stars** . **Key features**: **Automated production chains**; **conveyor belts and logistics**; **tower defense combat**; **campaign and multiplayer**; **mobile support**; mod support . **Best for**: Factorio and tower defense fans.

- **[Unciv](https://github.com/yairm210/Unciv)**  
  **Open-source Civ V clone for Android and desktop.** **MPL-2.0 licensed**, **9,000+ GitHub stars** . **Key features**: **Turn-based 4X strategy**; **civilizations and units**; **tech tree**; **multiplayer**; **mod support** . **Best for**: Civilization fans wanting a mobile-friendly open-source alternative.

### Additional Strong Open-Source Options

- **Full RTS**: **0 A.D.** (historical), **OpenRA** (C&C classics), **Beyond All Reason** (large-scale), **Warzone 2100** (unit customization), **Widelands** (Settlers-style) .
- **Tower Defense/Factorio**: **Mindustry** (factory + tower defense) .
- **4X Strategy**: **Unciv** (Civ V clone) .
- **Engine Frameworks**: **Godot Engine** (build custom RTS), **Spring Engine** (TA-style RTS engine), **OpenRTS** (three.js RTS framework) .

**Frameworks for building custom systems**: Combine **0 A.D.** for historical RTS campaigns, **OpenRA** for C&C-style action, **Beyond All Reason** for large-scale combat, **Widelands** for economic strategy, and **Mindustry** for tower defense/factory hybrid. Use **Godot Engine** or **Spring Engine** to build custom action-strategy games.
